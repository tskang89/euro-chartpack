# 주요국 경제 차트팩

Eurostat·ECB·OECD 공개 통계로 만드는 거시지표 차트팩.

**상단 5개 권역** 미국 · 중국 · 유로지역 · 일본 · 한국
**유로지역을 누르면** 유로 전체와 회원국 8개(독일·프랑스·이탈리아·스페인·
네덜란드·벨기에·아일랜드·오스트리아)가 2단으로 펼쳐집니다.

탭은 가로로 늘어놓지 않고 줄바꿈으로 접습니다. 휴대폰에서 옆으로 밀지 않아도
전부 보입니다(620px 아래에서는 영문을 접고 한글만 남깁니다).

**보기: https://tskang89.github.io/euro-chartpack/**

독일 조간 브리핑([german-news-brief](https://github.com/tskang89/german-news-brief))
맨 아래에서 이 주소로 연결됩니다.

## 구조

| 파일 | 하는 일 |
|---|---|
| `template.html` | 화면. 데이터가 들어갈 자리만 `__DATA__` 로 비어 있습니다 |
| `build/sources.py` | **계열 명세** — 어느 숫자가 어느 데이터셋의 어느 칸인지 |
| `build/eurostat.py` | Eurostat 배포 API 클라이언트 |
| `build/build.py` | 수집 → 주입 → `index.html` |
| `index.html` | 생성물. GitHub Pages 가 이것을 서빙합니다 |

숫자를 고치려면 `build/sources.py` 부터 보세요.

## 직접 돌리기

```bash
pip install -r requirements.txt
python build/build.py --check   # 쓰지 않고 지금 index.html 과 대조만
python build/build.py           # index.html 을 새로 쓴다
```

`--check` 는 "고친 데가 없는데 숫자가 달라졌다"를 잡으려는 것입니다. Eurostat 이
값을 수정하면 달라지는 게 맞으므로, 다르다고 해서 곧 오류는 아닙니다.

## 자동 갱신

매주 월요일 05:00 UTC 에 GitHub Actions 가 돌려서 달라진 수치가 있으면
`index.html` 을 되커밋합니다. Actions 탭에서 손으로도 돌릴 수 있고, 그때
`check_only` 를 켜면 무엇이 달라지는지 먼저 볼 수 있습니다.

## 지금 어디까지 왔나

**API 로 받는 계열 (자동 갱신):**
물가(HICP 종합·근원, 월간·연간), 실업률(전체·청년, 월간·연간), GDP(명목·성장률·
분기 전기비·전년동기비), 인구, 10년물 국채금리와 대독일 스프레드, 산업생산(전체·
제조업)·서비스생산, 소매판매, EC 서베이(ESI·산업·서비스·소비자), 정부부채·재정수지,
주택가격, 품목별 소비자물가(`itH` `itC`), 경상수지(`caQ` `caQp` `caA` `caAp`),
이민(개별국), 그리고 ECB 에서 환율(`fxUsd` `fxKrw` `fxA`)과 정책금리(`dfr` `mro`).

검증: 손으로 만든 원본과 **`caAp` 5개 값을 빼고 전부 한 숫자도 다르지 않게**
재현됩니다(약 2만 개 값). 그 5개의 사정은 `sources.py` 의 `CA_FILTERS` 위에
적어 두었습니다.

**OECD 는 호출이 몰리면 429 를 냅니다.** 그때 `Retry-After` 를 따르고, 없으면
20초부터 배로 늘려 최대 3분까지 기다립니다. 그래도 실패하면 **이전 판 값을
물려 쓰고** 로그에 남깁니다 — 한 번 실패했다고 차트가 화면에서 사라지면
안 됩니다. 워크플로 제한시간을 45분으로 둔 것도 이 대기 때문입니다.

`--check` 는 **직전 빌드물**과 견줍니다. 한 번 빌드하고 나면 기준선이 그쪽으로
옮겨가므로, 원본과의 대조는 처음 한 번만 뜻이 있습니다. 그 뒤로는 "지난주와
무엇이 달라졌나"를 보는 도구입니다.

**물려 쓰는 계열은 없습니다.** 유로 9개 지역은 39개 계열, 유로 밖 4개국은
11개 계열이 모두 API 에서 옵니다.

### 유로지역 밖은 계열이 다릅니다

Eurostat 은 EU 밖을 내지 않아 미국·중국·일본·한국은 **OECD SDMX**(`build/oecd.py`)
에서 받습니다. 공통 차트 9개 묶음(실질 GDP 성장률·대외교역·소비자물가·실업률·주가·
금리·환율·생산·경기선행지수와 심리)이 나오고, 유로 전용 차트(역내외 교역·
EU 기준 재정·HICP 품목별·이민 등)는 유로 탭에서만 나옵니다.

**정의가 같지 않습니다.** 물가는 HICP 가 아니라 각국 CPI, 심리지수는 EC 서베이
(응답 비율 차)가 아니라 OECD 합성지수(100 = 장기평균)입니다. 차트가 나라별로
따로 그려져 한 그림에 섞이지는 않지만, 수준을 그대로 견주면 안 됩니다.

**구멍 셋** — 0 으로 채우지 않고 비워 둡니다(0 은 그래프에서 급락으로 읽힘).

| 빈 곳 | 사정 |
|---|---|
| 중국 실업률 | OECD 에 비교 가능한 계열이 없습니다. 중국은 도시조사실업률을 따로 내지만 기준이 다릅니다 |
| 일본 기업심리 | 일본은 단칸(日銀短観)을 따로 발표해 OECD 지수에 안 들어갑니다 |
| 미국 대미달러 환율 | 자기 통화라 계열이 없습니다. 대신 **달러지수(ICE DXY)** 를 Yahoo 에서 받아 그 자리에 넣습니다 |

**심리지수는 나라 사이 수준을 견주면 안 됩니다.** OECD 가 각국 서베이를 원래
눈금 그대로 내보냅니다 — 미국 소비자는 50~85, 중국은 85~120, 한국은 -14~12 로
척도가 다릅니다. KEI 에 100 기준 진폭조정판은 없습니다. 처음에 각주를
"100 = 장기평균"이라고 적었다가 사실대로 바로잡았습니다. 나라 사이 비교가
되는 지표로는 **경기선행지수(CLI)** 를 따로 넣었습니다 — 이쪽은 100 이
장기추세이고 진폭이 맞춰져 있습니다.

**일본 소비자물가는 메웠습니다.** OECD 가 물가 분류 개편(COICOP 1999 → 2018)을
나라마다 다른 속도로 하고 있어서, 일본은 **2018 판에만** 있고 미국·한국·중국은
**1999 판에만** 있습니다. 한쪽만 보면 "일본은 자료가 없다"로 읽힙니다.
`sources.OECD_FALLBACK` 이 주 계열이 통째로 빈 블록만 예비 출처에서 다시
받습니다. FRED 도 확인했으나 거기 일본 물가는 전부 OECD MEI 출처라 2021~22년에
함께 멈춰 있습니다.

주가는 네 나라도 Yahoo 월말 종가(`^GSPC` `000001.SS` `^N225` `^KS11`)를 씁니다.
OECD 에도 있지만 지수(2021=100)라 유로 차트와 같은 그림이 되지 않습니다.

### 주가지수만 공식 통계가 아닙니다

Eurostat 에도 ECB 에도 개별국 주가지수가 없습니다. 실제로 받아 본 결과입니다.

| 후보 | 결과 |
|---|---|
| **Yahoo Finance** (채택) | 월말 종가가 원본과 538/540 일치 |
| OECD | 9개 지역 전부 있으나 **월평균 지수**(2015=100) — 차트의 뜻이 바뀜 |
| ECB | 유로스톡스 50 하나뿐이고 역시 월평균 |
| Stooq | 자바스크립트 작업증명 요구 — 스크립트로 불가 |

Yahoo 는 비공식 경로라 언제든 막힐 수 있습니다. 막히면 그 지수를 **비워 두고**
빌드 로그에 경고를 남깁니다. 옛 숫자를 최신인 척 보여 주지 않습니다.
정식 통계로 가야 한다면 OECD 로 바꿀 수 있고, 그때는 차트 각주도
"월평균 주가지수"로 함께 고쳐야 합니다.

### 기간 축은 스스로 밀립니다

새 달·새 분기·새 해가 나오면 축이 따라 움직입니다. 달력으로 계산하지 않고
**값이 실제로 있는 마지막 시점**에서 되짚습니다 — 통계마다 발표가 늦는 정도가
달라, 달력으로 밀면 아직 나오지도 않은 달이 빈칸으로 붙기 때문입니다.

기준은 그 주기에서 가장 빨리 나오는 것입니다: 월간은 HICP, 분기는 GDP, 연간은
명목 GDP, 이민은 그 자체. 주가지수 축(`monthsS`)만 한 달 더 긴데, 진행 중인
달의 시세를 보여 주기 때문입니다.

축이 밀린 판은 이전 판과 자리별로 견줄 수 없으므로 `--check` 가 대조를 건너뛰고
그 사실을 알립니다.

## 알아 둘 것

- **그리스의 Eurostat 코드는 `EL`** 입니다. `GR` 이 아닙니다. EU 는 ISO 코드가
  아니라 자체 관례를 씁니다. `GR` 로 물으면 **오류가 나지 않고 빈 응답**이 와서,
  "그리스는 통계를 제출하지 않는다"고 잘못 읽기 쉽습니다. 실제로 한 번
  그렇게 읽었습니다. 2020년 기준 그리스 몫은 84,221명입니다.
- **유로지역은 `EA21`** (불가리아 가입 이후 고정 구성, 과거 소급). `EA` 는 그때그때
  회원국이 바뀌는 집계라 과거와 현재가 같은 기준이 아닙니다. 2026-07 물가가
  EA 2.9 / EA21 3.0 으로 갈립니다. 예외는 10년물 금리 하나로, Eurostat 이 EA21
  집계를 내지 않아 `EA` 를 씁니다(`sources.GEO_OVERRIDE`).
- **소매판매는 `G47`** — 자동차는 빠지지만 **연료는 들어 있습니다.** 원본 각주가
  "자동차·연료 제외"라고 적고 있어 2026-09-25 에 바로잡았습니다.
- **반올림**은 5를 올리되, 부동소수점이 실제로 담은 값 기준입니다. `2.405` 는
  내부적으로 `2.40499…` 라서 `2.40` 이 맞습니다. 자세한 것은 `build.py` 의
  `half_up`.
- 검색 노출은 `robots.txt` 와 `noindex` 로 막아 두었습니다.
