# 유로지역 경제 차트팩

Eurostat·ECB 공개 통계로 만드는 유로지역·독일·프랑스·이탈리아·스페인·네덜란드·
벨기에·아일랜드·오스트리아 거시지표 차트팩.

**보기: https://tskang89.github.io/euro-chartpack/**

독일 조간 브리핑([german-news-brief](https://github.com/tskang89/german-news-brief))
맨 아래에서 이 주소로 연결됩니다.

## 구조

| 파일 | 하는 일 |
|---|---|
| `template.html` | 화면. 데이터가 들어갈 자리만 `__DATA__` 로 비어 있습니다 |
| `build/sources.py` | **계열 명세** — 어느 숫자가 어느 데이터셋의 어느 칸인지 |
| `build/eurostat.py` | Eurostat 배포 API 클라이언트 |
| `build/build.py` | 수집 → 주입 → `index.html` |
| `index.html` | 생성물. GitHub Pages 가 이것을 서빙합니다 |

숫자를 고치려면 `build/sources.py` 부터 보세요.

## 직접 돌리기

```bash
pip install -r requirements.txt
python build/build.py --check   # 쓰지 않고 지금 index.html 과 대조만
python build/build.py           # index.html 을 새로 쓴다
```

`--check` 는 "고친 데가 없는데 숫자가 달라졌다"를 잡으려는 것입니다. Eurostat 이
값을 수정하면 달라지는 게 맞으므로, 다르다고 해서 곧 오류는 아닙니다.

## 자동 갱신

매주 월요일 05:00 UTC 에 GitHub Actions 가 돌려서 달라진 수치가 있으면
`index.html` 을 되커밋합니다. Actions 탭에서 손으로도 돌릴 수 있고, 그때
`check_only` 를 켜면 무엇이 달라지는지 먼저 볼 수 있습니다.

## 지금 어디까지 왔나

**API 로 받는 계열 (자동 갱신):**
물가(HICP 종합·근원, 월간·연간), 실업률(전체·청년, 월간·연간), GDP(명목·성장률·
분기 전기비·전년동기비), 인구, 10년물 국채금리와 대독일 스프레드, 산업생산(전체·
제조업)·서비스생산, 소매판매, EC 서베이(ESI·산업·서비스·소비자), 정부부채·재정수지,
주택가격, 품목별 소비자물가(`itH` `itC`), 경상수지(`caQ` `caQp` `caA` `caAp`),
이민(개별국), 그리고 ECB 에서 환율(`fxUsd` `fxKrw` `fxA`)과 정책금리(`dfr` `mro`).

검증: 손으로 만든 원본과 **caAp 5개 값을 빼고 전부 한 숫자도 다르지 않게**
재현됩니다. 그 5개의 사정은 `sources.py` 의 `CA_FILTERS` 위에 적어 두었습니다.

**아직 물려 쓰는 것은 유로지역 이민 합계 하나뿐입니다.** `migr_imm1ctz` 에
그리스 값이 아예 없어 21개국 합계를 낼 수 없습니다(20개국 합은 2020년 기준
2,561천 명인데 원본은 2,645천 명). 20개국 합을 "유로지역"이라 적으면 조용히
틀린 수가 됩니다. 개별 8개국은 자동으로 갱신됩니다.

### 주가지수만 공식 통계가 아닙니다

Eurostat 에도 ECB 에도 개별국 주가지수가 없습니다. 실제로 받아 본 결과입니다.

| 후보 | 결과 |
|---|---|
| **Yahoo Finance** (채택) | 월말 종가가 원본과 538/540 일치 |
| OECD | 9개 지역 전부 있으나 **월평균 지수**(2015=100) — 차트의 뜻이 바뀜 |
| ECB | 유로스톡스 50 하나뿐이고 역시 월평균 |
| Stooq | 자바스크립트 작업증명 요구 — 스크립트로 불가 |

Yahoo 는 비공식 경로라 언제든 막힐 수 있습니다. 막히면 그 지수를 **비워 두고**
빌드 로그에 경고를 남깁니다. 옛 숫자를 최신인 척 보여 주지 않습니다.
정식 통계로 가야 한다면 OECD 로 바꿀 수 있고, 그때는 차트 각주도
"월평균 주가지수"로 함께 고쳐야 합니다.

### 기간 축은 스스로 밀립니다

새 달·새 분기·새 해가 나오면 축이 따라 움직입니다. 달력으로 계산하지 않고
**값이 실제로 있는 마지막 시점**에서 되짚습니다 — 통계마다 발표가 늦는 정도가
달라, 달력으로 밀면 아직 나오지도 않은 달이 빈칸으로 붙기 때문입니다.

기준은 그 주기에서 가장 빨리 나오는 것입니다: 월간은 HICP, 분기는 GDP, 연간은
명목 GDP, 이민은 그 자체. 주가지수 축(`monthsS`)만 한 달 더 긴데, 진행 중인
달의 시세를 보여 주기 때문입니다.

축이 밀린 판은 이전 판과 자리별로 견줄 수 없으므로 `--check` 가 대조를 건너뛰고
그 사실을 알립니다.

## 알아 둘 것

- **유로지역은 `EA21`** (불가리아 가입 이후 고정 구성, 과거 소급). `EA` 는 그때그때
  회원국이 바뀌는 집계라 과거와 현재가 같은 기준이 아닙니다. 2026-07 물가가
  EA 2.9 / EA21 3.0 으로 갈립니다. 예외는 10년물 금리 하나로, Eurostat 이 EA21
  집계를 내지 않아 `EA` 를 씁니다(`sources.GEO_OVERRIDE`).
- **소매판매는 `G47`** — 자동차는 빠지지만 **연료는 들어 있습니다.** 화면 각주가
  "자동차·연료 제외"라고 적고 있는데 사실과 다릅니다. 고칠 때 각주도 함께
  고쳐야 합니다.
- **반올림**은 5를 올리되, 부동소수점이 실제로 담은 값 기준입니다. `2.405` 는
  내부적으로 `2.40499…` 라서 `2.40` 이 맞습니다. 자세한 것은 `build.py` 의
  `half_up`.
- 검색 노출은 `robots.txt` 와 `noindex` 로 막아 두었습니다.
